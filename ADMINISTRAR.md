# Administrar Tungurahua Trail Plus

1. Entra a https://app.pagescms.org o a /admin desde tu web.
2. Inicia sesión con la cuenta GitHub de Tungurahua Trail Plus.
3. Instala/autoriza Pages CMS para el repositorio `tungurahua-trail-plus-web`.
4. Abre el repositorio. Pages CMS detectará `.pages.yml` automáticamente.
5. Edita Página principal, Carreras activas, Campeonato, Galería o Auspiciantes.
6. Al guardar, Pages CMS crea un commit en GitHub y Netlify vuelve a publicar la web automáticamente.

Para fotografías: usa los campos de imagen del panel. Se guardan en `assets/uploads`.
